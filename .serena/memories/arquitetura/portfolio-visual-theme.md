## Visual Theme - CyberMatrix Terminal

Chosen palette for the portfolio redesign:
- Background: #050203 (near-black)
- Surface: #030712 (rich black)
- Accent Green (primary): #73E65A (Matrix CRT green)
- Accent Purple: #711D9A (AI/neural dimension)
- Accent Cyan: #00FFFF (data-link layer)
- Accent Yellow: #FFCC00 (warnings/highlights)
- Accent Red: #FE4450 (errors)
- Text: #e0e0e0 (light gray)
- Text Secondary: #9ca3af
- Text Muted: #6b7280

Fonts: Space Grotesk (display), Inter (body), JetBrains Mono (mono)

Key design elements:
- Neural network particle canvas as hero background (nodes + connections + pulses)
- Glitch text effect for name
- Terminal-style About section
- Scroll progress bar (accent green)
- Animated stat counters
- Skill bars with staggered reveals
- Timeline experience layout
- Project cards with tech filters
- Easter egg: /doom page preserved
