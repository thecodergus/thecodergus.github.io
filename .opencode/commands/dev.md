# /dev

Inicia o servidor de desenvolvimento do SolidStart.

```bash
npm run dev
```

O servidor roda em `http://localhost:3000`. O hot reload é automático para
mudanças em arquivos `.ts`, `.tsx`, `.css`.

**Verificação:** Acesse `http://localhost:3000` e confirme que a página carrega
com o tema AI ativo e os textos em português.
